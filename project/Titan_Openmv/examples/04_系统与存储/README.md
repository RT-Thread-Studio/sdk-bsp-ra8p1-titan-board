# 时间、任务与文件系统

| 分类 | 示例 |
|---|---|
| 01_时间与任务 | ticks 周期任务、周期/一次性 Timer、asyncio 并发 LED、Event 通知 |
| 02_系统信息 | CPU 频率、唯一 ID、Python 堆与 board 内存信息、MSC 介质可见状态 |
| 03_文件系统 | 列目录、文本追加、二进制读写、JSON、创建/重命名/删除自有文件 |

文件系统脚本使用 SD 卡。路径为 `/`；`/rom` 是同一卷的只读别名。先结束电脑文件复制并安全弹出 MSC 卷，再运行板端文件写入脚本。电脑与板端同时写 FAT 不受支持。本目录不会自动格式化介质，也不会自动调用 `board.usb_msc(False)` 打断主机读写。详细部署见 [本板运行约定](../BOARD.md)。

SD 需预先具备有效 FAT；无介质时基础 Python、LED、Timer 等仍可用，文件操作会报错。无卡或配套 `openmv-vision.bin` 尚未验证完成时，不能运行视觉示例。已枚举 SD 拔出后需复位，不能用脚本热切换后端。

文本、二进制、JSON 例均生成未用过的文件名并保留结果；多次运行会占用空间。目录生命周期例只删除它当次创建的文件和目录。不要把示例保存成 `boot.py` 或 `main.py`，除非确实需要上电自动运行。

官方快照、GIF/MJPEG 录像、ImageIO 内存/文件流示例统一在 [01_视觉](../01_视觉/) 的相机分类中，避免重复维护。

Timer 使用 `period` 毫秒参数，当前没有 `freq` 关键字。asyncio 已冻结到固件，不需要联网安装；这里不使用关闭的 socket/network 或线程功能。日历 RTC 与低功耗 API 未启用，因此只演示单调计时。
