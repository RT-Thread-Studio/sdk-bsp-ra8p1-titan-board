# 传感器控制

运行前加载配套 `openmv-vision.bin`，在 OpenMV IDE 打开单个脚本。相机示例使用 OV5640。

| 示例 | 内容 | 使用条件 |
| --- | --- | --- |
| [sensor_auto_gain_control.py](sensor_auto_gain_control.py) | 自动增益控制 | 无需外部素材 |
| [sensor_exposure_control.py](sensor_exposure_control.py) | 曝光时间控制 | 无需外部素材 |
| [sensor_horizontal_mirror.py](sensor_horizontal_mirror.py) | 水平镜像 API | 当前 MIPI 输出方向固定，调用不改变图像方向 |
| [sensor_manual_gain_control.py](sensor_manual_gain_control.py) | 手动增益控制 | 无需外部素材 |
| [sensor_manual_whitebal_control.py](sensor_manual_whitebal_control.py) | 白平衡增益控制 | 无需外部素材 |
| [sensor_save_and_restore_settings.py](sensor_save_and_restore_settings.py) | 曝光与增益设置恢复 | 无需外部素材 |
| [sensor_vertical_flip.py](sensor_vertical_flip.py) | 垂直翻转 API | 当前 MIPI 输出方向固定，调用不改变图像方向 |
