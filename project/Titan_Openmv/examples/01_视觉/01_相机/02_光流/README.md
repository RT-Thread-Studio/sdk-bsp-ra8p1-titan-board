# 光流

运行前加载配套 `openmv-vision.bin`，在 OpenMV IDE 打开单个脚本。相机示例使用 OV5640。

| 示例 | 内容 | 使用条件 |
| --- | --- | --- |
| [absolute_rotation_scale.py](absolute_rotation_scale.py) | 绝对旋转与缩放光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [absolute_translation.py](absolute_translation.py) | 绝对平移光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [differential_rotation_scale.py](differential_rotation_scale.py) | 差分旋转与缩放光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [differential_translation.py](differential_translation.py) | 差分平移光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [image_patches_absolute_rotation_scale.py](image_patches_absolute_rotation_scale.py) | 分块绝对旋转与缩放光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [image_patches_absolute_translation.py](image_patches_absolute_translation.py) | 分块绝对平移光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [image_patches_differential_rotation_scale.py](image_patches_differential_rotation_scale.py) | 分块差分旋转与缩放光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
| [image_patches_differential_translation.py](image_patches_differential_translation.py) | 分块差分平移光流 | QVGA 采集，64×64/128×128 裁剪窗口；参考图和光流分块尺寸与窗口一致。 |
