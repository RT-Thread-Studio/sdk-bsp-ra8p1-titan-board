# 视觉示例

本目录包含 124 个视觉示例：相机、拍照录像、光流、绘图、滤波、颜色跟踪、帧差、条码、特征检测和 AprilTag。

运行前将当前固件配套的 `openmv-vision.bin` 放在存储介质根目录，等串口报告验证成功。连接 OpenMV IDE，单独打开一个 `.py` 运行。使用摄像头的示例需要本板 OV5640 MIPI；在固定光照下运行，颜色阈值、镜头校正系数与检测阈值需按现场调整。

相机采集端统一配置 `QVGA`（320×240）；光流配合 `window()` 获得 64×64 或 128×128，模板匹配使用 160×120 中心窗口。图像 `scale(hint=image.TRANSPOSE)` 是受支持的软件变换，不调用未实现的相机转置采集。自动对焦、动态 readout、事件相机、热成像、ToF、全局快门功能未开放。

人脸拍照/录像及 `lbp.py` 保留官方 `/rom/haarcascade_frontalface.cascade`。本板 `/rom` 是存储根目录的只读别名：把本目录 `assets/haarcascade_frontalface.cascade` 复制到 U 盘根目录，不用建立 `rom` 文件夹。模型为完整 25 级，许可保留在 `assets/LICENSE.frontalface.txt`。`lbp.py` 中官方打印的 `Match %` 实际是 LBP 描述符距离（越小越相近），并非匹配百分比。

写文件的示例需要可写 FAT（SD 卡）。运行时请让电脑停止访问该盘；运行结束后再读取文件。示例会创建或覆盖注释中列出的 `example.*`、`stream.bin`、`desc.*`、`temp/` 和 `timelapse/` 文件。运动/人脸触发脚本会重复保存，请留足空间并在观察到结果后停止。原始流限制为 24 帧；内存流限制为 20 帧。定时拍照例持续供电计时，不使用此端口尚未实现的 RTC 唤醒和深睡眠。

AprilTag 与二维码是不同编码，AprilTag 示例默认识别 TAG36H11。三维位姿例保留六自由度打印；示例内参来自上游演示，必须使用实际 OV5640 镜头标定参数才能作定量测量。没有检测结果时，先确认标签家族、目标清晰度与照明。

各示例独立运行，按实际镜头、光照、目标和存储条件调整参数。
