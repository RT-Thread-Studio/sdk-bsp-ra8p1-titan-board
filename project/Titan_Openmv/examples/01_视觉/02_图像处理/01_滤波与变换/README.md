# 滤波与变换

运行前加载配套 `openmv-vision.bin`，在 OpenMV IDE 打开单个脚本。相机示例使用 OV5640。

| 示例 | 内容 | 使用条件 |
| --- | --- | --- |
| [adaptive_histogram_equalization.py](adaptive_histogram_equalization.py) | 自适应直方图均衡 | 无需外部素材 |
| [blur_filter.py](blur_filter.py) | 高斯模糊 | 无需外部素材 |
| [color_bilateral_filter.py](color_bilateral_filter.py) | 彩色双边滤波 | 无需外部素材 |
| [color_binary_filter.py](color_binary_filter.py) | 彩色阈值二值化 | 无需外部素材 |
| [color_correction.py](color_correction.py) | 颜色矩阵校正 | 固件内置 ulab |
| [color_light_removal.py](color_light_removal.py) | 彩色光照归一化 | 无需外部素材 |
| [edge_filter.py](edge_filter.py) | 拉普拉斯边缘滤波 | 无需外部素材 |
| [erode_and_dilate.py](erode_and_dilate.py) | 腐蚀与膨胀 | 无需外部素材 |
| [gamma_correction.py](gamma_correction.py) | 伽马校正 | 无需外部素材 |
| [grayscale_bilateral_filter.py](grayscale_bilateral_filter.py) | 灰度双边滤波 | 无需外部素材 |
| [grayscale_binary_filter.py](grayscale_binary_filter.py) | 灰度二值化 | 无需外部素材 |
| [grayscale_light_removal.py](grayscale_light_removal.py) | 灰度光照归一化 | 无需外部素材 |
| [histogram_equalization.py](histogram_equalization.py) | 直方图均衡 | 无需外部素材 |
| [kernel_filters.py](kernel_filters.py) | 自定义卷积核 | 无需外部素材 |
| [lens_correction.py](lens_correction.py) | 镜头畸变校正 | 无需外部素材 |
| [linear_polar.py](linear_polar.py) | 线性极坐标变换 | 无需外部素材 |
| [linear_polar_off_center.py](linear_polar_off_center.py) | 偏心线性极坐标变换 | 无需外部素材 |
| [log_polar.py](log_polar.py) | 对数极坐标变换 | 无需外部素材 |
| [log_polar_off_center.py](log_polar_off_center.py) | 偏心对数极坐标变换 | 无需外部素材 |
| [mean_adaptive_threshold_filter.py](mean_adaptive_threshold_filter.py) | 均值自适应阈值 | 无需外部素材 |
| [mean_filter.py](mean_filter.py) | 均值滤波 | 无需外部素材 |
| [median_adaptive_threshold_filter.py](median_adaptive_threshold_filter.py) | 中值自适应阈值 | 无需外部素材 |
| [median_filter.py](median_filter.py) | 中值滤波 | 无需外部素材 |
| [midpoint_adaptive_threshold_filter.py](midpoint_adaptive_threshold_filter.py) | 中点自适应阈值 | 无需外部素材 |
| [midpoint_filter.py](midpoint_filter.py) | 中点滤波 | 无需外部素材 |
| [mode_adaptive_threshold_filter.py](mode_adaptive_threshold_filter.py) | 众数自适应阈值 | 无需外部素材 |
| [mode_filter.py](mode_filter.py) | 众数滤波 | 无需外部素材 |
| [negative.py](negative.py) | 图像反色 | 无需外部素材 |

| [perspective_correction.py](perspective_correction.py) | 透视校正 | 无需外部素材 |
| [rotation_correction.py](rotation_correction.py) | 旋转校正 | 无需外部素材 |
| [sharpen_filter.py](sharpen_filter.py) | 锐化滤波 | 无需外部素材 |
| [ulab.py](ulab.py) | 图像转数值数组 | 固件内置 ulab |
| [unsharp_filter.py](unsharp_filter.py) | 非锐化掩蔽 | 无需外部素材 |
