# 条码

运行前加载配套 `openmv-vision.bin`，在 OpenMV IDE 打开单个脚本。相机示例使用 OV5640。

| 示例 | 内容 | 使用条件 |
| --- | --- | --- |
| [find_barcodes.py](find_barcodes.py) | 一维条码识别 | 无需外部素材 |
| [find_datamatrices.py](find_datamatrices.py) | DataMatrix识别 | 无需外部素材 |
| [find_datamatrices_w_lens_zoom.py](find_datamatrices_w_lens_zoom.py) | 裁剪放大DataMatrix识别 | 无需外部素材 |
| [qrcodes_with_lens_corr.py](qrcodes_with_lens_corr.py) | 畸变校正二维码识别 | 无需外部素材 |
| [qrcodes_with_lens_zoom.py](qrcodes_with_lens_zoom.py) | 裁剪放大二维码识别 | 无需外部素材 |
